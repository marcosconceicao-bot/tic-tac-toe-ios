# 🚀 V1.2 Release Notes - "Social & Economy"

## 📅 Release Date: February 13, 2026

## 🎉 Major Features Implemented

### 🪙 **Virtual Coin System**
- **Earn coins** for winning games (5-30 coins based on difficulty)
- **Speed bonuses** for quick wins
- **Achievement rewards** (25-200 coins per achievement)
- **Welcome bonus** of 100 coins for new players
- **Rewarded ads** for free coins (25 coins per ad)

### 🛒 **Virtual Shop**
- **10+ purchasable items** across 4 categories:
  - **Themes**: Galaxy, Ocean, Forest (150-200 coins)
  - **Symbols**: Emoji, Hearts, Gaming symbols (75-125 coins)
  - **Effects**: Particle effects, Sound packs (250-300 coins)
  - **Power-ups**: Hints, Undo moves (25-50 coins)
- **Purchase persistence** with local storage
- **Insufficient funds** handling with ad options

### 🎯 **Daily Challenges System**
- **7 different challenge types**:
  - Win 3 games (75 coins)
  - Beat Hard AI (100 coins)
  - Play 5 games (50 coins)
  - Speed wins under 30s (125 coins)
  - Perfect games (150 coins)
  - Use different themes (60 coins)
  - Comeback victories (100 coins)
- **Streak tracking** with flame icon
- **Push notifications** for new challenges
- **Automatic rotation** based on day of year

### 🎮 **Multiplayer Foundation**
- **GameCenter integration** ready
- **Real-time matchmaking** system
- **Data transmission** for moves and game state
- **Leaderboards & achievements** infrastructure
- **Authentication handling** with proper UI flows
